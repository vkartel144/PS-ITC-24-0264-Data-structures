 Real-World Applications of Arrays as a Data Structure

 1. Introduction 

An array is a data structure used to store multiple elements of the same data type under one variable name. Each element is accessed using an index, which starts from 0 in C++.

 2. Real-World Applications of Arrays

1. Student Management System: Stores students' examination marks and helps calculate their average scores.
2. Banking System: Stores transaction records and amounts for calculations.
3. E-commerce System: Stores product prices and quantities.
4. Hospital Management System: Stores patient records and appointment information.
5. Weather Forecasting System: Stores daily temperature and rainfall measurements.
6. Inventory Management System: Stores product quantities and prices.
7. Gaming Applications: Stores players' scores and game-board positions.

 3. Why Arrays Are Necessary

Arrays are useful because they:
- Store multiple related values under one variable name.
- Allow elements to be accessed using indexes.
- Make it easier to process data using loops.
- Reduce the need to declare many separate variables.
- Support calculations such as totals, averages, maximums, and minimums.
- Help organize related data.

 4. Selected Application: Student Marks Management System

 Aim

The aim is to develop a program that stores the examination marks of five students, calculates the total and average marks, and identifies the highest and lowest marks.

Use of Arrays

The program uses the array:

`int marks[5] = {75, 80, 65, 90, 70};`

The array stores five students' marks. Each mark has an index from 0 to 4.

Expected Results

- Total marks: 380
- Average mark: 76
- Highest mark: 90
- Lowest mark: 65

 Why Arrays Are Suitable

Arrays are suitable because the program stores several marks of the same data type. A loop processes each mark, while conditional statements identify the highest and lowest marks. This makes the program organized and reduces repetitive code.

 5. Conclusion

Arrays are important in programming because they help store, organize, access, and process related data efficiently. The Student Marks Management System demonstrates how arrays can be used to calculate and analyze students' examination results.
